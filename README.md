⏰ DeadlineKiller
Android-приложение для тех, у кого всегда есть дедлайны — и всегда не хватает времени.

DeadlineKiller помогает не пропустить важные сроки: создавайте задачи, помечайте их тегами, следите за прогрессом и держите дедлайны под контролем.

📌 О проекте
Приложение решает простую, но болезненную проблему — соблюдение дедлайнов. Оно подойдёт всем, у кого есть сроки: студентам, фрилансерам, разработчикам, менеджерам — словом, каждому, кто устал держать задачи в голове.

Нативные технологии Android, локальное хранение данных и ничего лишнего.

✨ Возможности
➕ Создание дедлайнов — быстро добавить задачу и указать срок

🗑 Удаление — убрать выполненное или ненужное

🏷 Теги — группировка и фильтрация задач по категориям

📊 Статистика — наглядный обзор ваших дедлайнов и прогресса

📖 Использование
Добавить дедлайн — нажмите «+», укажите название, срок и тег.

Управлять задачами — редактируйте, отмечайте выполненными, удаляйте.

Фильтровать по тегам — быстро находите нужную категорию.

Смотреть статистику — оценивайте, сколько задач выполнено и сколько ещё впереди.

💡 Скриншоты появятся здесь — добавьте изображения в папку /screenshots и вставьте ссылки.
